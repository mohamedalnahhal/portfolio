## Appearance

The theme follows your system preference until you use the top-right toggle; your choice is then saved in the browser. Dark mode uses a `#0a0a0a` background and `#00ff9c` accent. The light accent remains configurable in `src/config.ts`.

## Selected projects

To show project screenshots, add an optional `screenshots` array to that project in `src/config.ts`. Put local images in `public/projects/` and use paths such as `/projects/dashboard.png`. Each image needs descriptive alternative text; omit the array to keep a text-only card. Multiple screenshots get previous/next controls automatically.

```ts
screenshots: [
  { src: "/projects/dashboard.png", alt: "Dashboard showing project activity" },
  { src: "/projects/settings.png", alt: "Project settings screen" },
],
```
